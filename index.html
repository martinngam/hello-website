Curriculum

What you'll learn

Six modules that build on each other, from first install to team-wide workflows.

01

Getting started

Install Claude Code, connect it to your projects, and learn how to give clear instructions.

02

Understanding a codebase

Explore unfamiliar code, ask questions about it, and get up to speed on new projects quickly.

03

Building & fixing

Plan features, write and edit code, debug failures, and refactor safely with tests.

04

Git & GitHub workflows

Commit, branch, open pull requests and review changes, with Claude Code doing the heavy lifting.

05

Customizing Claude Code

Project instructions (CLAUDE.md), permissions, hooks, skills and MCP connections to your tools.

06

Rolling out to your team

Best practices, security, shared settings and measuring the impact on your engineering work.

FAQ

Common questions

Do I need to be an expert programmer?

No. You should be comfortable with basic programming and the command line. We'll cover the rest.

What do I need to bring?

A laptop with internet access. We'll help you set up Claude Code and an account at the start of the course.

Is the course taught in Chinese?

Yes. Every session is available in English or Chinese, and course materials are provided in both languages.

Can you train our whole team?

Yes. Private team training can be tailored to your codebase, tools and schedule. Contact us for details.
